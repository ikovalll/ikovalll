Python backend developer focused on **Django** and **Django REST Framework**. I build web

GitHub Actions. Completed the Python Developer programme at Yandex Practicum — **open to
backend roles**.

`🛠 REST APIs on DRF` · `🧪 pytest & unittest` · `🐳 Docker + Nginx` · `⚙️ CI/CD on GitHub Actions` · `📚 learning async Python & FastAPI`
