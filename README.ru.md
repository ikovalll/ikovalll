## 📖 Обо мне

Python-разработчик бэкенда, специализируюсь на Django и Django REST Framework. Делаю
веб-приложения и API, покрываю их тестами, упаковываю в Docker и доставляю на серверы
через GitHub Actions. Закончил программу «Python-разработчик» в Яндекс Практикуме,
открыт к предложениям по бэкенду.

- 🛠 Разрабатываю REST API на Django REST Framework
- 🧪 Пишу тесты на pytest и unittest
- 🐳 Контейнеризирую проекты с Docker и Nginx
- ⚙️ Автоматизирую деплой через GitHub Actions
- 📚 Сейчас изучаю асинхронный Python и FastAPI
