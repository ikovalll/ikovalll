### 🧑‍💻 Обо мне

Python-разработчик бэкенда, специализируюсь на **Django** и **Django REST Framework**.
Делаю веб-приложения и API, покрываю тестами, упаковываю в Docker и доставляю на серверы
через GitHub Actions. Закончил программу «Python-разработчик» в Яндекс Практикуме —
**открыт к предложениям по бэкенду**.

`🛠 REST API на DRF` · `🧪 pytest и unittest` · `🐳 Docker + Nginx` · `⚙️ CI/CD на GitHub Actions` · `📚 учу асинхронный Python и FastAPI`
